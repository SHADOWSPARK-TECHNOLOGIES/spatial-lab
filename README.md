# spatial-lab

Experimental ShadowSpark spatial lab. Not production Lodgist. Not a fork of God's Eye View.

## Boundary

Spatial context for property decisions. No named-person tracking, cameras, aircraft, ships, or satellites.

## Sequence

1. v0 neighborhood: property pin, roads, hospitals, schools, markets, pharmacies, transit, labels.
2. v1 traffic and weather, only after a source is cleared.
3. v2 terrain.
4. v3 AI summary, labeled as inference.
5. v4 WhatsApp spatial ask.

## Rules

- Secret provider keys stay on lodgist-api, never in the browser.
- MIT code may be adapted with its license notice. Third-party data is not MIT.
- Area context is not a safety rating.
- See docs/DATA_SOURCES.md and .agents/skills/shadowspark-spatial-intelligence/SKILL.md.
